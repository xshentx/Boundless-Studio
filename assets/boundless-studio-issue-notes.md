### 01. 画布节点报错：Request body is empty

![画布节点报错：Request body is empty](assets/01-request-body-empty.png)

现象说明：

- 画布中某个生成节点显示红色错误提示：`Request body is empty`。
- 该错误出现在节点内部，同时顶部也有同样的 toast 提示。
- 初步判断这不是应用启动失败，而是某次图像生成/编辑请求失败。

排查记录：

- 本地 Boundless Studio 服务可访问：`/client-api/health` 返回正常。
- 数据库中画布状态记录了同样的错误：`Request body is empty`。
- 失败节点的 prompt 非空，当前不属于“提示词为空”导致的失败。
- 失败节点引用了本地参考图 storage key，例如 `image:nOSHr_AVjxbMNsoKCKAQ5`。
- 该参考图本地媒体缓存返回 `Content-Length: 0`，本地文件大小为 `0B`。
- 同一张图的远端 `backendUrl` 可下载到有效 PNG，说明远端图片存在，本地缓存写入结果异常。

当前结论：

- 截图中的错误更像是“参考图本地缓存为空”引发的后续请求失败。
- 生成镜头时走图像编辑接口，需要把参考图塞进请求体；如果本地参考图是 `0B`，上游会收到空文件或空请求内容，从而报 `Request body is empty`。

### 02. 删除已生成视频时跳回主页

![删除已生成视频时跳回主页](assets/02-delete-video-goes-home.png)

现象说明：

- 画布中已经生成了一个视频节点，右侧可见视频预览和播放控制条。
- 用户选中生成的视频内容后，按键盘删除键。
- 实际结果：应用跳回主页。
- 预期结果：只在当前画布中删除被选中的视频节点/视频内容，不应离开画布页面。

复现步骤：

1. 在画布中生成视频，或打开已有视频节点。
2. 点击选中已生成的视频内容。
3. 按键盘删除键。
4. 观察页面是否仍停留在当前画布，以及视频节点是否被删除。

初步判断：

- 这是画布页面的键盘事件处理问题。
- 删除键被触发后，当前选中对象应走画布节点删除逻辑，但实际发生了页面级导航或返回主页逻辑。
- 后续排查时应重点检查视频节点、预览控件、画布全局快捷键之间的 `Delete` / `Backspace` 事件冒泡与默认行为处理。

### 03. 选中已生成视频后连线锚点向下偏移

![选中已生成视频后连线锚点向下偏移](assets/03-video-edge-handle-offset.png)

现象说明：

- 视频生成完成后，右侧视频节点显示为视频预览卡片。
- 点击选中该视频节点时，节点外框和控制点位置正常显示在视频卡片周围。
- 但从左侧输入/生成节点连到右侧视频节点的连线终点明显偏到视频节点下方，没有连接到节点左侧的实际锚点位置。
- 截图中橙色连线在视频节点左下方落点，视觉上与节点边缘锚点脱节。

用户补充原因：

- 原本视频节点下方有输入框。
- 出视频后输入框被隐藏。
- 隐藏后节点视觉高度变小，但连线/锚点计算仍像保留了下方输入框高度一样，导致连线向下偏移。

预期结果：

- 视频生成完成并隐藏输入框后，节点尺寸、连接锚点和连线布局应同步刷新。
- 选中视频节点时，连线应连接到视频节点边缘实际显示的锚点，不应落到节点下方空白位置。

初步判断：

- 这是视频节点状态切换后的布局同步问题。
- 可能原因是隐藏输入框只改变了 DOM 可见内容，但 React Flow 节点高度或 handle 坐标没有重新测量。
- 后续排查时应重点检查视频节点生成完成后的条件渲染、节点尺寸缓存、`updateNodeInternals` 调用，以及连接 handle 的定位样式。

### 04. 画布助手无法选择模型，且标题显示“未开发”

![画布助手无法选择模型，且标题显示“未开发”](assets/04-assistant-model-select-no-response.png)

现象说明：

- 右侧画布助手面板标题显示为 `画布助手(未开发)`。
- 底部模型选择区域当前显示 `codex-auto-review`。
- 点击模型选择控件/下拉箭头后没有反应，无法展开模型列表，也无法切换模型。

实际结果：

- 模型选择点击无响应。
- 用户无法在画布助手中选择可用模型。
- 页面仍显示“未开发”字样，容易让用户误以为该功能不可用。

预期结果：

- 点击模型选择控件后应正常展开模型列表。
- 选择某个模型后，画布助手应使用所选模型进行后续对话、问答或生图相关操作。
- 标题中的 `未开发` 字样应移除，显示为 `画布助手`。

初步判断：

- 这是画布助手面板底部模型选择器的交互问题。
- 后续排查时应重点检查模型选择控件是否被遮罩层、按钮禁用状态、事件冒泡阻断、弹层挂载层级或 z-index 影响。
- 同时需要检查画布助手标题文案来源，把 `画布助手(未开发)` 改为正式文案。

## 修复建议

### 05. 1k 图片尺寸应改为 1024x1024

![图像设置：尺寸与生成张数](assets/05-image-settings-size-and-count.png)

当前问题：

- 图像设置中 `1k` 对应的实际图片尺寸不正确，目前出现约 `1254` 的尺寸结果。
- `1k` 应对应标准 `1024x1024`。

建议修改：

- 将 `1k` 图片规格固定为 `1024x1024`。
- 其他比例下也应以 `1k` 的标准短边/基准尺寸派生，避免出现非预期的 `1254` 尺寸。

### 06. 去除“生成质量”，改为 1k / 2k / 4k 图片选择；默认生成数量改为 1

![图像设置：生成质量入口](assets/06-image-quality-to-resolution-options.png)

当前问题：

- 图像设置中存在 `清晰度` / `生成质量` 选项，例如 `自动`、`low`、`medium`、`high`。
- 用户期望的是直接选择图片规格，而不是选择抽象质量档位。
- 当前默认生成数量是 `3`，期望默认只生成 `1` 张。

建议修改：

- 去除 `生成质量` / `清晰度` 文案和 `low`、`medium`、`high` 质量档位。
- 改为图片规格选择：`1k`、`2k`、`4k`。
- 默认图片规格建议为 `1k`。
- 默认生成张数从 `3` 改为 `1`。

### 07. 主页缺少“下载画布”功能

当前问题：

- 主页缺少下载画布的入口。
- 用户无法从主页直接导出或下载画布内容。

建议修改：

- 在主页增加 `下载画布` 功能入口。
- 下载内容应覆盖当前画布项目需要迁移/备份的核心数据，例如节点、连线、文本、图片/视频引用及必要的本地资源索引。
- 后续可补充主页截图，用于标注按钮建议位置和交互入口。
